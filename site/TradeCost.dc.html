What is an "executed order"?
An executed order is a buy or sell instruction that actually went through. One buy and one sell is 2 orders. If your broker fills a big order in several parts and charges for each, count each executed part. Brokerage is worked out on each part's value, assuming the parts are equal in size. Your contract note from the broker shows the exact count.

How was this calculated?
Brokerage per executed order = max(min(0.1% × order value, ₹20), ₹5), but never more than 2.5% × order value
Exchange charges = 0.00307% · SEBI fee = ₹10 per crore · IPFT = ₹0.01 per crore, each on that side's value
GST = 18% of (brokerage + exchange charges + SEBI fee + IPFT)
STT = 0.1% of the value, on buy and on sell, rounded to the rupee · Stamp duty = 0.015% of the buy value, rounded to the rupee
You pay = buy value + buy-side charges · You receive = sell value − sell-side charges
Taxable gain = sell value − buy value − all charges except STT · Tax = 20% (12 months or less) or 12.5% (longer), only if above zero · Cess = 4% of the tax
What you keep = you receive − you pay − tax − cess
Check against a real contract note: a ₹1,997.40 buy gives brokerage ₹5.00, exchange ₹0.06, GST ₹0.91, STT ₹2.00, stamp ₹0.00, so you pay ₹2,005.37. A ₹2,198.60 sell gives ₹5.00, ₹0.07, ₹0.91 and ₹2.00, so you receive ₹2,190.62.
Formula F13 in the project methodology. If an order was filled in several executed parts, each part is assumed to be the same size. Brokerage and its GST are treated as deductible; this is to be confirmed by a chartered accountant. Tax is rounded to the paisa, and the cess is worked on the rounded tax. All arithmetic is exact, in paise.
