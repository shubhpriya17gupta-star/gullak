# Gullak: working rules

## Stay in scope (saves credits)
- Work only on the page, section or element discussed in the current chat. Do not edit, refactor, restyle or "tidy" anything else on the site.
- Search narrowly: grep for the exact text or identifier first, then read only the lines around it. Do not read or scan whole pages or the whole `site/` folder unless the task needs it.
- Do not spawn subagents, run broad reviews, or run the full test suite unless asked. Run only the test for the calculator you changed.
- If a change would also affect another page, say so in one line and ask before touching it.
- Keep replies short: what changed, where, and anything that needs a decision.
